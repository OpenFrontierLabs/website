How it works

From idle compute to open frontier models.

Islands of GPUs train locally for many steps, then sync compressed updates rarely. Slow links cost little, and nodes can join or leave without stopping the run. This is the design; none of it has run yet.

  1. Your Idle Compute

    A spare machine or GPU, offered to a run.

  2. Distributed Training Network

    Islands will join through a small coordinator and object storage.

  3. Shared Checkpoints

    Every checkpoint will be published as the run goes.

  4. Open Models

    Final weights will be open for anyone to use, build on and improve.

  5. Public Evidence

    Configs, logs and a credit ledger will be open to check.

Try it today

Don't take our word for it. Run it.

The scaffolding is real. Clone the repo and the smoke test trains a tiny model with the pinned OLMo-core trainer, then runs a reference DiLoCo across two workers. CPU only, no GPU needed.

Works today

  • CPU smoke run of the pinned OLMo-core trainer
  • Reference DiLoCo on two CPU workers
  • Run 0 launcher, config and pinned upstreams
  • A doctor that checks your node

Not built yet

  • Joining a shared training run
  • Coordinator and node agent
  • Dropping updates that hurt the loss
  • Any trained checkpoint or weights

The stack

Eight layers, from your GPU to open models.

Today only part of the web platform is live: sign-up and the waitlist. Every other layer is planned.

  1. 8

    Outputs

    Open models, open weights, open checkpoints, open datasets, open research and open training evidence.

    Planned
  2. 7

    Hosting

    Cloudflare Workers and D1 for the site and app; Durable Objects, R2, regional relay VPSs and Hugging Face publishing come later. The website can be centralized; the training network should not be.

    Planned
  3. 6

    Web platform

    This site. Sign-up with GitHub, the waitlist and its questionnaire, the contributor workspace and the Operator Console's Review Queue work today; node, run and receipt data wait for the Node app.

    Live, partly
  4. 5

    Storage and evidence

    safetensors with manifests, public checkpoints, dataset shards, evidence receipts and an audit trail, on Hugging Face and mirrors.

    Planned
  5. 4

    Training engine

    Mode A: DiLoCo-style async data parallel with compressed, low-bandwidth sync. Mode B: sharded training with stage placement and elastic recovery. Only a CPU smoke test exists today.

    Planned
  6. 3

    Decentralized network

    rust-libp2p over QUIC/TCP: bootstrap peers, membership, peer discovery, relays and NAT traversal, signed protocol messages.

    Planned
  7. 2

    Open Frontier Node

    Runs on contributor machines: hardware discovery, resource limits, checkpoint recovery, local logs, CLI and desktop UI, signed device identity.

    Planned
  8. 1

    Contributor hardware

    NVIDIA GPUs (CUDA, PyTorch, Triton), Apple Silicon (MLX, Metal, incl. M5/M6), AMD GPUs (ROCm), CPU and test nodes.

    Planned
