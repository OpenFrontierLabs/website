Manifesto

What OpenAI should have been, with a pure community vibe.

Frontier intelligence should be built in public and owned by the people who build it.

  1. 1

    Everything is open. Data recipes, code, configs, logs, every checkpoint and the final weights, released as they happen under permissive licences.

  2. 2

    Owned by the community. A nonprofit foundation structure is planned to hold the repos, marks and weights. Decisions happen in public.

  3. 3

    No equity, no token, no closed tier. Nobody sits between the community and the model.

  4. 4

    Credit for everyone who contributes. Compute and work are credited by name, publicly and permanently.

  5. 5

    Negative results are results. We publish what failed, and why.

  6. 6

    Best at each size, not frontier theatre. We aim to be the best open model at each scale we train, and we say plainly where we stand.

Pillars

Open Infrastructure

Trainers, data pipelines, a node agent and dashboards, all in public repositories anyone can clone and run.

Distributed Compute

How it works

Islands of GPUs, synced rarely.

Every pooled machine or cluster is an island: synchronous inside, DiLoCo-style across. Islands train locally for many steps, then exchange compressed updates (int8 or sparser) through a small coordinator and object storage. Slow links cost little, and nodes can join or leave without stopping the run.

Islands

Community nodes and donated clusters. Synchronous training inside each island.

pseudo-gradients, int8 compressed, infrequent

Elastic mesh

Merges updates across islands and catches new nodes up from a live checkpoint.

every step logged

Checkpoints and weights

Every checkpoint, log and the final Apache-2.0 weights are published.

Compute pooling planned

Joining is meant to be one command line. The ofl CLI is not built yet; this is the planned flow.

# check the machine: GPUs, drivers, bandwidth, latency, clock, disk
ofl doctor
# join a run; the node catches up from a live checkpoint
ofl join run1

Nodes whose updates hurt the loss are dropped automatically. Rollouts for RL and evals are meant to accept any GPU; early pretraining is realistically for 8-GPU nodes and donated clusters.

Public credit ledger planned

Credit is public and tied to repository history. A ledger in the runs repository will record, per node:

  • GPU-hours contributed
  • Tokens processed
  • Share of updates that helped the loss

Model cards will name compute contributors and donors by GitHub handle.

Roadmap

Four steps. All of it is planned.

Nothing has been trained yet. Sizes below are targets, not results, and will change as we learn what pooled compute can do.

  1. Run 0

    planned

    About 1B parameters, Qwen3-style dense model, trained with DiLoCo across 4 to 8 nodes in at least two regions. A first reproducible run: configs, logs and every checkpoint.

  2. Run 1

    planned

    About 10B parameters, our first community base model. Donated clusters join as islands; a live public dashboard shows the run.

  3. Distributed RL, in parallel

    planned

    prime-rl style asynchronous RL with community-built environments. Starts on an existing open base (Olmo 3) to prove the swarm, then moves to our own.

  4. Run 2

    planned

    30B to 70B parameters, as large as the pooled and donated compute allows, on the same pipeline.
